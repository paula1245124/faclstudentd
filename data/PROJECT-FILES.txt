1) قبل ما تبدأ — نظرة عامة
═══════════════════════════════════════════════════════════════════════

🗂️ هيكل الملفات:

  project/
  ├── indexV5.html                       ← الصفحة الرئيسية (مش هتتغير)
  └── data/
      ├── subjects-index.js              ← فهرس المواد
      ├── computer-networks.js           ← ملف المحاضرات والأسئلة
      ├── sections-computer-networks.json ← ملف السكاشن
      ├── sample.js
      └── sections-sample.json


🔑 المفاهيم الأساسية:

  ┌────────────────┬───────────────────────────────────┬──────────────────┐
  │ المفهوم        │ معناه                              │ مثال              │
  ├────────────────┼───────────────────────────────────┼──────────────────┤
  │ المادة         │ ملف JS فيه كل محاضرات مادة واحدة   │ computer-networks│
  │ المحاضرة       │ كائن داخل lectures[]               │ مقدمة الشبكات    │
  │ السكشن         │ كائن داخل sections[] في JSON       │ سكشن A — م. أحمد  │
  │ المعيد         │ شخص، وله instructorId ثابت         │ inst-ahmed       │
  │ المجموعة       │ اسم المجموعة تحت المعيد            │ "سكشن A"         │
  └────────────────┴───────────────────────────────────┴──────────────────┘

   قبل أي إضافة، خد نسخة احتياطية من الملف اللي هتعدّله.
   لو حصل خطأ، ترجع في ثانية.

2) إضافة محاضرة جديدة
═══════════════════════════════════════════════════════════════════════

📝 الخطوة 1: افتح ملف المادة
   مثال: data/computer-networks.js

📝 الخطوة 2: حدّد آخر محاضرة موجودة
   دوّر على lectures: [ وافتح آخر قوس } قبل ].

📝 الخطوة 3: ضيف فاصلة (,) بعد آخر محاضرة
   كان:
       }    ← آخر محاضرة قديمة
     ]      ← قوس إغلاق lectures

   يبقى:
       },   ← ★ ضيف فاصلة هنا
     ]

📝 الخطوة 4: انسخ القالب التالي والصقه بعد الفاصلة:

    // ═══════════════════════════════════════════════
    // المحاضرة الرابعة — [اسم المحاضرة]
    // ═══════════════════════════════════════════════
    {
      id: "net-lecture-04",
      t: "المحاضرة الرابعة — Transport Layer",
      d: "TCP, UDP, Flow Control, Congestion Control",
      pdf: "files/net-4.pdf",
      pdf2: "files/net-4-questions.pdf",
      sectionTitle: "🧩 سكاشن Transport Layer",

      links: [
        { t: "🎥 تسجيل الفيديو", d: "المحاضرة كاملة", url: "https://example.com/net-4-video" },
        { t: "📑 السلايدات", url: "https://example.com/net-4-slides" }
      ],

      linkCategories: [
        {
          category: "فيديوهات عربية",
          icon: "🇪🇬",
          description: "شروحات بالعربية",
          links: [
            {
              t: "شرح TCP vs UDP",
              d: "مقارنة مبسطة بالعربي",
              icon: "🇪🇬",
              actions: [
                { label: "📖 الشرح", url: "https://youtube.com/...", type: "view", color: "red" }
              ]
            }
          ]
        }
      ],

      questions: [
        {
          q: "ما الفرق بين TCP و UDP؟",

      }
    }

📝 الخطوة 5: تحقق من صحة القوس
   بعد الإضافة، الملف لازم يبان كده:

     lectures: [
       { /* محاضرة 1 */ },
       { /* محاضرة 2 */ },
       { /* محاضرة 3 */ },
       { /* محاضرة 4 الجديدة */ }   ← آخر واحد بدون فاصلة
     ],


✅ علامات النجاح:
   [ ] id فريد (مش مكرر مع محاضرة تانية)
   [ ] t مليان
   [ ] الفاصلة , بعد كل محاضرة ما عدا الأخيرة
   [ ] الأسئلة موجودة (ولو سؤال واحد)
   [ ] type: "essay" موجود في الأسئلة المقالية

3) إضافة سكشن جديد
═══════════════════════════════════════════════════════════════════════

📝 الخطوة 1: افتح ملف السكاشن
   مثال: data/sections-computer-networks.json

📝 الخطوة 2: حدّد آخر سكشن
   دوّر على آخر } قبل ] النهائية.

📝 الخطوة 3: ضيف فاصلة (,) بعد آخر سكشن
   كان:
       }     ← آخر سكشن
     ]       ← قوس إغلاق sections

   يبقى:
       },    ← ★ ضيف فاصلة
     ]

📝 الخطوة 4: انسخ القالب التالي والصقه:

    {
      "id": "net-sec-05",
      "subject": "computer-networks",
      "lectureId": "net-lecture-04",
      "lecture": "المحاضرة الرابعة — Transport Layer",

      "instructorId": "inst-ahmed",
      "instructorName": "م. أحمد سمير",
      "groupName": "سكشن A",
      "status": "available",

      "sectionTitle": "🧩 سكاشن Transport Layer",

      "notes": "الحضور إجباري — في تمارين عملية.",

      "materials": {
        "file":      { "label": "ملف السكشن",   "url": "files/net-sec-05.pdf",     "type": "pdf" },
        "exercises": { "label": "تمارين",        "url": "files/net-sec-05-ex.pdf",  "type": "pdf" },
        "solution":  { "label": "الحل النموذجي", "url": "files/net-sec-05-sol.pdf", "type": "pdf" },
        "recording": "https://example.com/net-sec-05-record",
        "extraLinks": [
          { "label": "مراجعة على YouTube", "url": "https://youtube.com/..." }
        ]
      },

      "extraFiles": [
        { "label": "ملف تمارين إضافي", "url": "files/net-sec-05-extra.pdf", "type": "pdf" },
        { "label": "شرح إضافي",        "url": "https://example.com/extra",   "type": "video" }
      ],

      "task": {
        "title": "واجب الأسبوع الرابع",
        "url": "files/net-sec-05-task.pdf",
        "dueDate": "2026-05-15",
        "notes": "سلّم قبل الساعة 11 مساءً — الإجابة عبر Google Form."
      }
    }

⚠️ ملاحظة مهمة عن instructorId:
   - لو نفس المعيد موجود في سكاشن سابقة → استخدم نفس الـ instructorId.
   - لو معيد جديد → اختر instructorId جديد مثل inst-mohamed.


✅ علامات النجاح:
   [ ] id فريد لكل سكشن
   [ ] lectureId يطابق id المحاضرة اللي في ملف المادة
   [ ] subject يطابق slug المادة في subjects-index.js
   [ ] instructorId ثابت لكل معيد (نفس المعيد = نفس الـ ID)
   [ ] الفاصلة , بعد كل سكشن ما عدا الأخير

4) شرح كل الحقول بالتفصيل
═══════════════════════════════════════════════════════════════════════

🎯 أ) حقول المحاضرة:

  ┌──────────────┬──────────┬────────┬────────────────────┬───────────────────┐
  │ الحقل        │ النوع    │ إجباري │ القيم الممكنة       │ ملاحظات           │
  ├──────────────┼──────────┼────────┼────────────────────┼───────────────────┤
  │ id           │ string   │ ✅     │ أي نص فريد          │ net-lecture-04    │
  │ t            │ string   │ ✅     │ أي نص               │ عنوان المحاضرة    │
  │ d            │ string   │ ❌     │ أي نص               │ وصف قصير          │
  │ pdf          │ url/path │ ❌     │ ملف PDF             │ ملف المحاضرة      │
  │ pdf2         │ url/path │ ❌     │ ملف PDF             │ ملف أسئلة منفصل   │
  │ sectionTitle │ string   │ ❌     │ أي نص               │ عنوان قسم السكشن  │
  │ links[]      │ array    │ ❌     │ كائنات روابط         │ روابط مباشرة      │
  │ linkCategories[] │ array│ ❌     │ فئات روابط          │ روابط مجمّعة      │
  │ questions[]  │ array    │ ❌     │ أسئلة MCQ/مقالي      │ بنك الأسئلة       │
  │ notes        │ string   │ ❌     │ أي نص               │ ملاحظات وتكاليف   │
  │ summary      │ object   │ ❌     │ {pdf, text}         │ ملخص              │
  └──────────────┴──────────┴────────┴────────────────────┴───────────────────┘


🎯 ب) حقول السكشن:

  ┌────────────────┬──────────┬────────┬─────────────────────────┬───────────────┐
  │ الحقل          │ النوع    │ إجباري │ القيم                    │ ملاحظات       │
  ├────────────────┼──────────┼────────┼─────────────────────────┼───────────────┤
  │ id             │ string   │ ✅     │ فريد                     │ net-sec-01    │
  │ subject        │ string   │ ✅     │ نفس slug المادة          │ للتصفية       │
  │ lectureId      │ string   │ ✅*    │ يطابق id المحاضرة         │ الأفضل        │
  │ lecture        │ string   │ ✅*    │ عنوان المحاضرة           │ بديل          │
  │ instructorId   │ string   │ ✅     │ فريد للمعيد              │ inst-ahmed    │
  │ instructorName │ string   │ ✅     │ اسم المعيد               │ يظهر للمستخدم │
  │ groupName      │ string   │ ❌     │ "سكشن A"                │ تمييز         │
  │ status         │ string   │ ❌     │ available/soon/unavailable│ الافتراضي:    │
  │                │          │        │                         │ available     │
  │ sectionTitle   │ string   │ ❌     │ أي نص                    │ عنوان القسم   │
  │ notes          │ string   │ ❌     │ أي نص                    │ ملاحظة المعيد │
  │ materials      │ object   │ ❌     │ انظر تحت                 │ ملفات أساسية  │
  │ extraFiles[]   │ array    │ ❌     │ ملفات إضافية              │ ملفات إضافية  │
  │ task           │ object   │ ❌     │ انظر تحت                 │ ملف المهمة    │
  └────────────────┴──────────┴────────┴─────────────────────────┴───────────────┘

  * واحد منهم على الأقل مطلوب.


🎯 ج) حقول materials (اختيارية كلها):

  ┌─────────────┬─────────────────┬──────────────────────────────────────┐
  │ المفتاح     │ النوع           │ مثال                                  │
  ├─────────────┼─────────────────┼──────────────────────────────────────┤
  │ file        │ string أو object│ "files/x.pdf" أو {label, url, type}  │
  │ exercises   │ string أو object│ نفس الشكل                             │
  │ solution    │ string أو object│ نفس الشكل                             │
  │ recording   │ url             │ رابط فيديو (لازم https)              │
  │ extraLinks[]│ array           │ [{label, url}]                       │
  └─────────────┴─────────────────┴──────────────────────────────────────┘


🎯 د) حقول task:

  task: {
    title:   "واجب الأسبوع الرابع",        ← ★ عنوان المهمة
    url:     "files/task.pdf",            ← ★ رابط الملف
    dueDate: "2026-05-15",                ← ★ تاريخ التسليم (YYYY-MM-DD)
    notes:   "سلّم قبل الساعة 11 مساءً."   ← ملاحظات
  }


🎯 هـ) أنواع الأسئلة:

  MCQ (اختيار من متعدد):
    {
      q: "السؤال؟",                          ← ★ إجباري
      options: ["أ", "ب", "ج", "د"],         ← ★ إجباري (2 على الأقل)
      correct: 1,                             ← ★ index الإجابة (يبدأ من 0)
      translation: "...",                    ← اختياري
      explanation: "..."                     ← اختياري
    }

  مقالي (Essay):
    {
      type: "essay",                          ← ★ إجباري
      q: "السؤال؟",                          ← ★ إجباري
      answer: "الإجابة النموذجية...",          ← ★ إجباري
      tags: ["tag1", "tag2"],                ← اختياري
      ref: "المحاضرة 4 — Section 3.5"        ← اختياري
    }


🎯 و) أنواع الروابط:

  رابط بسيط:
    { t: "الاسم", d: "الوصف", url: "https://..." }

  رابط مع أزرار متعددة:
    {
      t: "الاسم",
      d: "الوصف",
      icon: "🔗",
      actions: [
        { label: "مشاهدة", url: "https://...", type: "view",     color: "blue" },
        { label: "تحميل",  url: "https://...", type: "download", color: "green" }
      ]
    }

  الألوان المتاحة: green, orange, red, blue
  الأنواع: view, download

5) أخطاء شائعة وكيفية تجنبها
═══════════════════════════════════════════════════════════════════════

❌ خطأ 1: نسيان الفاصلة
   lectures: [
     { /* محاضرة 1 */ }     ← مفيش فاصلة
     { /* محاضرة 2 */ }     ← ❌ هيكسر
   ]
   الحل: فاصلة (,) بعد كل عنصر ما عدا الأخير.

❌ خطأ 2: تكرار id
   { id: "net-lecture-04", t: "..." }
   { id: "net-lecture-04", t: "..." }   // ❌ نفس الـ ID
   الحل: كل id فريد.

❌ خطأ 3: عدم تطابق lectureId
   ملف المحاضرة: { id: "net-lecture-04" }
   ملف السكشن:   { "lectureId": "net-lecture-05" }   // ❌ مش هيظهر
   الحل: اتأكد lectureId = id المحاضرة بالظبط.

❌ خطأ 4: subject غير متطابق
   subjects-index.js: { slug: "computer-networks" }
   sections.json:     { "subject": "computer-network" }  // ❌
   الحل: انسخ slug من subjects-index.js حرفيًا.

❌ خطأ 5: المعيد نفسه بـ IDs مختلفة
   { "instructorId": "inst-ahmed" }
   { "instructorId": "ahmed-1" }    // ❌ هيظهر كشخصين
   الحل: نفس المعيد = نفس instructorId دائمًا.

❌ خطأ 6: instructorId متطابق لمعيدين مختلفين
   { "instructorId": "inst-001", "instructorName": "م. أحمد" }
   { "instructorId": "inst-001", "instructorName": "م. سارة" }  // ❌
   الحل: كل معيد = instructorId خاص به.

❌ خطأ 7: JSON غير صالح
   { "sections": [ { "id": "x", } ] }   // ❌ فاصلة قبل }
   الحل: استخدم JSONLint للتأكد.

❌ خطأ 8: أسئلة بدون correct
   { q: "السؤال؟", options: ["أ", "ب"] }   // ❌ نسيت correct
   الحل: MCQ لازم correct: <index>.

❌ خطأ 9: correct أكبر من عدد options
   { options: ["أ", "ب"], correct: 5 }   // ❌ index 5 مش موجود
   الحل: correct بين 0 و options.length - 1.

❌ خطأ 10: روابط بـ http:// بدل https://
   { "recording": "http://example.com/video" }   // ❌
   الحل: كل الروابط الخارجية لازم https://.

        category: "[فئة]",

        description: "[وصف]",

✅ قائمة فحص سريعة:

  1. افتح الصفحة في المتصفح → F12 → Console
  2. اتأكد مفيش أخطاء JS
  3. روح للمادة → اتأكد المحاضرة الجديدة ظاهرة
  4. اضغط عليها → اتأكد:
     [ ] العنوان ظهر صح
     [ ] عدد الأسئلة = العدد اللي أضفته
     [ ] الروابط شغالة
  5. افتح قسم السكشن → اتأكد:
     [ ] لو معيد واحد → دخل مباشرةً
     [ ] لو أكثر → ظهرت القائمة
     [ ] لو نفس المعيد بأكثر من سكشن → ظهر المنتقي
  6. افتح سكشن → اتأكد:
     [ ] الملفات الأساسية ظاهرة
     [ ] extraFiles ظاهرة تحت "📎 ملفات إضافية"
     [ ] task ظاهر تحت "📌 ملف المهمة"
